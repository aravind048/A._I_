# Python Variables

## What is a variable?

A variable is a name that refers to a value or object.

For example:

x = 10

Here, x refers to the value 10.

## Assignment

Assignment stores a value under a variable name.

For example:

x = 10
x = x + 2

The second statement uses the current value of x, adds 2, and assigns the result back to x.

Therefore:

print(x)

Output:

12

## Using multiple variables

Variables can be used together.

For example:

x = 5
y = 2

print(x * y)

Output:

10

## Common misconception

A common beginner mistake is thinking that:

x = x + 2

means that the value of x is mathematically equal to itself plus 2.

In programming, it means:

1. Read the current value of x.
2. Add 2.
3. Store the new value back in x.

## Worked example

x = 10
y = x + 5

print(y)

Output:

15
